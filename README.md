# WASEET — وسيط للاستشارات والخدمات الاستشارية (B2C Egypt)

> **"كل خبرة تحتاجها، تجدها في وسيط."**

منصة وسيط (WASEET) هي أول منصة وساطة استشارية متكاملة مصممة خصيصاً لسوق جمهورية مصر العربية وفق نموذج **B2C (Business-to-Consumer)**، تربط العملاء الأفراد وأصحاب المشروعات بنخبة المستشارين والخبراء المعتمدين في أكثر من 26 تخصصاً استشارياً، مع حماية كاملة للمدفوعات تحت نظام الضمان المالي المزدوج (Escrow) بالجنيه المصري (EGP).

---

## 🌟 أبرز مميزات المنصة

1. **26+ تخصصاً استشارياً معتمداً:**
   - الضرائب ومنظومة الفاتورة والإيصال الإلكتروني.
   - تأسيس الشركات بالهيئة العامة للاستثمار (GAFI) وقانون الشركات.
   - الاستشارات القانونية والتجارية وصياغة العقود.
   - المحاسبة والمراجعة المالية ودراسات الجدوى المعتمدة.
   - الذكاء الاصطناعي ومعمارية النظم والبرمجيات السحابية.
   - التسويق الرقمي والتجارة الإلكترونية، وغيرها الكثير.

2. **حماية الضمان المالي الكاملة (Escrow Workflow):**
   - لا يتم تحويل قيمة الاستشارة للمستشار إلا بعد انعقاد الجلسة واعتماد العميل للمخرجات.
   - تسوية النزاعات ورد المبالغ عبر قيود محاسبية عكسية فورية.

3. **دفتر الأستاذ العام بالقيد المزدوج (Double-Entry Ledger):**
   - حفظ المعاملات بوحدة القروش (BIGINT Integer Piasters) لمنع أخطاء التقريب المالي.
   - التوازن التام: `Total Debits == Total Credits`.
   - احتساب عمولة الوساطة 15% للمنصة و8% للتسويق بالعمولة (Affiliate).

4. **محرك حجز ذكي بدون تعارض (Conflict-Free Scheduling):**
   - توليد المواعيد المتاحة آلياً وفق أيام وساعات عمل المستشار.
   - تطبيق الفواصل الزمنية (Buffer Time) وفترة الإخطار المسبق.
   - دعم التوقيت المحلي لجمهورية مصر العربية (`Africa/Cairo`).

5. **سوق عروض الأسعار التنافسية (RFQ Marketplace):**
   - إمكانية نشر العميل لطلب استشارة أو دراسة بميزانية محددة وتلقّي عروض الأسعار من المستشارين المعتمدين والمفاضلة بينها.

6. **مساحة عمل الطلبات والمخرجات والمراسلات (Order Workspace):**
   - تبادل المخرجات والتقارير الفنية.
   - محادثة كتابية داخلية موثقة بين العميل والمستشار لكل طلب.
   - إدارة طلبات التعديل والنزاعات.

7. **مساعد وسيط الذكي (WASEET AI Assistant):**
   - مدعوم بـ Google Gemini API عبر خادم وسيط الآمن.
   - توجيه العميل للتخصص الأنسب وصياغة أسئلة الاستشارة وموجز الـ RFQ، مع تنبيه قانوني صارم بعدم تقديم نصائح بديلة عن الخبير المرخص.

8. **نظام صلاحيات متكامل (RBAC):**
   - عميل (Client)، مستشار (Consultant)، مدير منصة (Admin)، خدمة عملاء (Support)، مسوق بالعمولة (Affiliate)، شريك (Partner)، وبائع أدوات (Seller).

## 🗄️ المخطط العلائقي لقاعدة البيانات (PostgreSQL)

الملف `database/schema.sql` يحتوي على المخطط الكامل مع المفاتيح الأجنبية، الفهارس، والقيود:
- `users`, `user_sessions`, `roles`, `permissions`
- `categories`, `consultant_profiles`, `consultant_credentials`
- `consultation_services`, `availability_rules`, `availability_exceptions`
- `bookings`, `orders`, `rfq_requests`, `rfq_proposals`
- `conversations`, `messages`, `disputes`
- `ledger_accounts`, `ledger_transactions`, `ledger_entries`
- `audit_logs`, `support_tickets`, `products`

## 🚀 التشغيل المحلي (Local Development)

### المتطلبات الأساسية
- **Node.js**: الإصدار 18 أو أحدث.
- **npm** أو **pnpm**.

### خطوات التشغيل
1. تثبيت الاعتماديات:
   ```bash
   npm install
   ```

2. إعداد المتغيرات البيئية:
   قم بنسخ `.env.example` إلى `.env`:
   ```bash
   cp .env.example .env
   ```
   *(قم بوضع مفتاح `GEMINI_API_KEY` عند الرغبة في تفعيل المساعد الذكي المباشر).*

3. تشغيل التطبيق في وضع التطوير (Full-Stack Express + Vite):
   ```bash
   npm run dev
   ```
   التطبيق متاح الآن على: `http://localhost:3000`

4. تشغيل الاختبارات الآلية (Unit Tests):
   ```bash
   npx --yes tsx --test src/utils/ledger.test.ts src/utils/booking.test.ts
   ```

5. فحص التوافق وTypeScript Lint:
   ```bash
   npm run lint
   ```

## 🛡️ معايير الأمن السيبراني
- حفظ المبالغ النقدية بالقروش (`BIGINT`) لتفادي ثغرات التقريب.
- منع الحجز المزدوج وتعارض المواعيد على مستوى الخوارزمية وقاعدة البيانات.
- عزل استدعاءات الذكاء الاصطناعي على الخادم (`server.ts`) لحماية مفتاح API.
- تسجيل العمليات الحساسة في جدول التدقيق الأمني (`audit_logs`).
- حماية المعاملات ضد التكرار باستخدام مفاتيح المعاملات الوحيدة (`Idempotency Keys`).
